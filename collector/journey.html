What each queue contains

SYN tracking concerns incomplete handshakes. The accept queue holds established connections awaiting acceptance. A socket receive queue holds bytes. The epoll interest list is the subscription set; its ready list references descriptors ready for I/O. The CPU scheduler run queue holds runnable threads. These are different structures, not a single HTTP-request queue.

Connection setup is shared across HTTP keepalive requests. HTTP/2 streams share a socket, so readiness and reads cannot automatically be assigned to one stream. POST_READ occurs after header parsing; its offset does not start at NIC arrival.
